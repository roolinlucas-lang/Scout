Configuración de Supabase

  1. Creá un proyecto en supabase.com.
  2. Abrí SQL Editor → New query.
  3. Copiá todo el contenido de supabase_setup.sql incluido en este ZIP y ejecutalo.
  4. En Project Settings → API copiá Project URL y la clave pública (anon/publishable).
  5. Pegá esos dos valores arriba, guardá y creá tu cuenta.
  6. Si Supabase pide confirmar el email, abrí el correo y confirmalo.
  7. Importá tu copia JSON y tocá «Subir datos a la nube».
  8. En otro dispositivo abrí la misma web, configurá las mismas credenciales, iniciá sesión y tocá «Descargar datos de la nube».
Nunca pegues aquí la clave service_role, secret key, contraseña de Supabase ni tokens privados. Solo la clave pública anon/publishable.
